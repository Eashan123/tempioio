# Gate I Companion Structure Reference

This documents the structure used for the Gate I: Influence & Creation companion ebook. Use as a reference, not a rigid template — other gates will require different structures.

**Main teaching:** Intent, imagery, timing, ancestry — the four mechanics of programming reality.

**Companion focus:** Physical altar objects needed to practice petition work.

## What Worked

- Tables for every item category made sourcing clear
- Three-tier kit structure covers all budgets
- Archetype section matched Gate I's deity emphasis
- Lunar timing reference is something readers will return to
- First ritual gives immediate action step

## What to Adapt for Other Gates

- **Archetype section:** Only if deity work is central to that gate
- **Altar layout:** Only if spatial arrangement matters
- **Timing reference:** Adapt to what timing matters (lunar, daily, seasonal)
- **Kit contents:** Completely different items per gate
- **First practice:** Different activation based on gate's core practice
